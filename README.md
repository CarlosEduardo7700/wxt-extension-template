# WXT + React

This template should help get you started developing with React in WXT.

# Sobre

O objetivo deste template será **eliminar a fricção entre a ideia e o lançamento**, servindo como o atalho definitivo para o **Indie Hacker** que precisa validar produtos com agilidade. Em um cenário onde o tempo é o recurso mais escasso, este projeto será o **alicerce técnico** para transformar conceitos em extensões funcionais e monetizáveis em tempo recorde.

### O que este ecossistema entregará:

* **Foco total em Time-to-Market:** Utilizar a stack **WXT + React + Tailwind CSS** para garantir que a criação de interfaces modernas e responsivas seja feita com o mínimo de esforço.
* **Integração Nativa com o Backend:** Estar "pré-conectado" ao nosso **Template de API NestJS**, incluindo clientes HTTP configurados para lidar com o *Cold Start* de plataformas como o Render e injeção automática de tokens JWT.
* **Autenticação e Segurança Prontas:** Oferecer um sistema de login funcional com hooks de autenticação (`useAuth`) integrados ao `chrome.storage.local`, garantindo sessões persistentes e seguras sem configuração manual.
* **Prontidão para Distribuição:** Incluir scripts de build automatizados e comandos de empacotamento (`zip`) que geram os arquivos finais prontos para submissão imediata na Chrome Web Store.
* **Arquitetura Modular:** Permitir que o projeto comece simples, mas suporte a adição de *Background Scripts*, *Content Scripts* e páginas de Opções conforme a necessidade de cada Micro-SaaS.

### Objetivo Final
O propósito será permitir a construção de um **sistema Full Stack completo** que rode em infraestrutura gratuita (como Render e Supabase), possibilitando que você valide múltiplos projetos com custo zero até que o produto se torne rentável.

> **"Construa rápido, valide logo, escale apenas o que funciona."**
